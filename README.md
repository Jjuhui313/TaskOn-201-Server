# 🚀 Taskon

실시간 협업을 위한 백엔드 시스템
WebSocket 기반 실시간 채팅과 Elasticsearch 기반 검색 기능을 제공하는 협업 서비스



## 📌 프로젝트 소개

Taskon은 사용자들이 협업을 위해 사용할 수 있는 서비스로
다음과 같은 핵심 기능을 제공합니다.

- OAuth2 기반 로그인

- JWT 기반 인증 시스템

- WebSocket 기반 실시간 채팅

- Elasticsearch 기반 검색 기능

- Docker 기반 서비스 배포


이 프로젝트에서는 다음과 같은 기술적 문제를 해결하는 것을 목표로 했습니다.

- WebSocket 환경에서 인증 처리

- 실시간 채팅 시스템 설계

- 검색 성능 개선

- Docker 기반 배포 환경 구축

## 🛠 Tech Stack
Backend
